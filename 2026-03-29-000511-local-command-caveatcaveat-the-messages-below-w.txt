⏺ Here's a clear picture of the current state and what can be added:

  Current MCP: 1 tool (tell_story) — blindly overwrites the story JSON. The LLM
  can't observe, navigate, or control individual aspects.

  ---
  Expansion areas

  1. Observability — get_story

  The LLM currently writes blind. Add a read tool so it can see what's loaded
  before iterating:
  { "tool": "get_story" }  →  returns current story JSON + current scene index

  2. Scene navigation — go_to_scene

  Instead of the user manually pressing ←/→, let the LLM drive the presentation:
  { "tool": "go_to_scene", "scene": 4 }
  Writes to public/story/control.json; the frontend polls it separately from the
   story.

  3. Auto-advance / timing — duration per scene

  Add a duration field to each scene so the LLM can pace the story:
  { "narration": "...", "duration": 6000 }  // 6s then auto-advance

  4. Location markers — markers per scene

  Pin cities or events on the globe with labels:
  "markers": [
    { "lat": 35.7, "lng": 51.4, "label": "Tehran", "color": "#c0392b" },
    { "lat": 26.2, "lng": 50.6, "label": "Strait of Hormuz", "color": "#e8a020"
  }
  ]
  These require a new Three.js renderer in GlobeSceneCanvas.vue (sprite + text).

  5. Camera overrides per scene

  Override the auto-framing for specific scenes:
  "camera": { "lat": 27, "lng": 56, "zoom": 1.8 }
  Currently the camera auto-computes centroid from highlights/arcs; this would
  skip that for dramatic shots.

  6. Scene-level title/headline

  Currently only the story has a title. Each scene could have a short sceneTitle
   displayed as a bold header above narration.
