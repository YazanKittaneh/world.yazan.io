### Task 4: Implement the globe scene component

**Files:**
- Create: `components/globe/GlobeSceneCanvas.vue`
- Reference: `components/hero/HeroSceneCanvas.vue`
- Reference: `composables/globeConfig.ts`

**Step 1: Create the component shell**

Structure it like the existing hero canvas:

```vue
<script setup lang="ts">
import * as THREE from 'three'
// three-globe must be dynamically imported inside onMounted — it accesses window.THREE
// at module-init time and will crash during SSR if imported at the top level.
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js'
import countries from '~/data/globe/countries.geo.json'
import { globeConfig } from '~/composables/globeConfig'

const containerRef = ref<HTMLDivElement | null>(null)
</script>

<template>
  <div ref="containerRef" class="globe-scene-canvas" />
</template>
```

**Step 2: Build the Three.js scene lifecycle**

Implement:
- scene creation
- perspective camera
- renderer creation
- resize listener
- animation loop
- cleanup on unmount

Follow the disposal patterns from `HeroSceneCanvas.vue`.

**Step 3: Mount the globe object**

`three-globe` must be dynamically imported inside `onMounted` to avoid the `window is not defined` SSR crash:

```ts
const { default: ThreeGlobe } = await import('three-globe')
```

**`.polygonLabel()` does not exist in `three-globe` 2.45.x** — omit it entirely.

To use a custom texture (e.g. grayscale), skip `.globeImageUrl()` and pass a `MeshPhongMaterial` directly via `.globeMaterial()`. When using `.globeMaterial()`, set `waitForGlobeReady: false`:

```ts
const globeMat = new THREE.MeshPhongMaterial({ map: grayscaleTex })

const globe = new ThreeGlobe({ waitForGlobeReady: false })
  .globeMaterial(globeMat)
  .showAtmosphere(true)
  .atmosphereColor(globeConfig.atmosphereColor)
  .atmosphereAltitude(globeConfig.atmosphereAltitude)
  .polygonsData(countries.features)
  .polygonAltitude(globeConfig.polygonAltitude)
  .polygonCapColor(() => globeConfig.polygonCapColor)
  .polygonSideColor(() => globeConfig.polygonSideColor)
  .polygonStrokeColor(() => globeConfig.polygonStrokeColor)
```

Available polygon methods in 2.45.x: `polygonsData`, `polygonCapColor`, `polygonCapMaterial`, `polygonSideColor`, `polygonSideMaterial`, `polygonStrokeColor`, `polygonAltitude`, `polygonCapCurvatureResolution`, `polygonsTransitionDuration`.

**Step 4: Add controls and editorial motion**

Configure `OrbitControls` for:
- rotate enabled
- pan disabled
- zoom enabled
- damping enabled
- constrained distance range
- gentle auto-rotation when idle

If `OrbitControls` auto-rotate is insufficient, apply a slow `globe.rotation.y` increment in the render loop when not interacting.

**Step 5: Add scene lighting**

Use a minimal but deliberate lighting rig:
- ambient light
- directional light or hemisphere light

Do not overbuild the lighting if the globe texture already carries the look.
